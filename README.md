1. 텍스트 전처리(Normalization) 로직 개선

위치: import 선언부 (약 8번째 줄 부근), normalize_question 함수 (약 45~46번째 줄)

설명: 기존 46번째 줄의 return q.strip().lower().replace("?", "").replace(" ", "") 코드는 띄어쓰기를 모두 없애버려 형태소 단위의 한국어 의미를 훼손했습니다. 파일 상단에 정규표현식(import re) 패키지를 추가하고, 해당 함수를 "한글과 띄어쓰기를 유지하며 불필요한 특수문자만 필터링"하도록 수정하여 캐시와 오버레이의 의미 기반 검색 정확도를 높였다고 설명하시면 됩니다.

2. 한국어 임베딩 모델 교체

위치: embed_query 함수 (약 51번째 줄)

설명: 기존 51번째 줄에 model="nomic-embed-text"로 설정되어 있던 부분을 model="bge-m3"로 변경했습니다. 기존에 설정된 모델은 영문 및 코드 위주라 한국어 질문의 미묘한 차이를 잘 구분하지 못했기 때문에, 다국어 문맥 파악에 뛰어난 최신 임베딩 모델로 교체하여 벡터(Vector) 초벌 검색 성능을 근본적으로 개선했다고 말씀하시면 됩니다.

3. Reranker(재랭킹) 모델 도입으로 할루시네이션 방지

위치: 전역 변수 선언부 (약 20번째 줄 부근), search_chunks 함수 전체 (약 81~91번째 줄)

설명: 81번째 줄부터 시작하는 기존 search_chunks 함수는 단순 벡터 코사인 유사도(Cosine Similarity)를 계산해 상위 5개를 가져오는 1차원적인 구조였습니다. 파일 상단에 CrossEncoder("Dongjin-kr/ko-reranker")를 전역으로 로드하고, 해당 함수를 "1차로 15개의 문서를 넓게 뽑은 뒤, Reranker 모델이 질문과 문서의 문맥 연관성을 꼼꼼히 채점하여 가장 정답에 가까운 핵심 문서 3개만 반환"하도록 완전히 뜯어고쳐 검색 정확도를 극대화했다고 강조하시면 됩니다.

4. 시스템 프롬프트(System Prompt) 엔지니어링

위치: generate_answer 함수 내 (약 106~112번째 줄)

설명: 기존 108~111번째 줄에 작성되었던 시스템 프롬프트는 단순 텍스트로만 이루어져 있어, 모델이 제약을 과하게 인식하고 "문서에 없는 내용입니다"를 고장 난 기계처럼 반복하는 문제가 있었습니다. 이를 '[지시사항]'이라는 명확한 넘버링 구조로 개편하고, 마크다운(Markdown) 포맷팅 강제 및 "관련 정보가 없을 땐 단 한 번만 말해라"는 예외 처리 규칙을 명시하여 최종 응답의 가독성과 시스템 안정성을 모두 확보했다고 설명하시면 완벽합니다.
